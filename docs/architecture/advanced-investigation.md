# Advanced investigation and route ownership

Graph traversal, retrieval internals, agent traces and specialist diagnostics live behind one Advanced Investigation destination rather than appearing as primary service-desk language. The workspace is read-only, tenant-scoped, role-gated and unavailable without diagnostic consent. Every node and relationship carries evidence IDs; graph size, trace history and retrieval results are bounded and deterministically ordered.

Every application page has an explicit owner in the role-aware shell or is an intentional public entry route. The validator compares filesystem pages to the navigation registry, so incomplete and orphaned pages fail the build instead of silently shipping.
