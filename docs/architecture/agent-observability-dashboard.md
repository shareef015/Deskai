# Agent Observability and Quality Dashboard

The observability dashboard accepts only allowlisted privacy-safe span fields. Raw prompts, model completions, tool arguments and endpoint output are excluded. Tenant and environment mode are mandatory filters.

Graph views connect nodes, agents and routing outcomes with latency, tokens, cost, tool authorization, classified failures, retries and circuit state. Quality and drift measures come from governed evaluations rather than operator edits.

Summaries derive SLO, drift and open-circuit alerts from bounded telemetry. Synthetic recruiter traces remain isolated from live production measurements while demonstrating the same operational contracts.
