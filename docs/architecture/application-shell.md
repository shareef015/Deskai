# Role-aware application shell

The authenticated shell derives destinations from the server-validated tenant, role and live/synthetic session mode. Unauthorized destinations are omitted and rejected at the route boundary. Navigation is grouped by support work instead of implementation terminology, and the synthetic demonstration destination never appears in live mode.

The desktop sidebar becomes an accessible modal drawer on narrow screens. Escape, the close button, backdrop selection and route changes close it; focus returns to the menu trigger. Breadcrumbs expose location, tenant/mode badges prevent context confusion, and reusable loading, error and empty states keep every route predictable.
