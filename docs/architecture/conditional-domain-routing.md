# Conditional Domain Routing

Domain classification is an advisory, scored input to a deterministic policy router. The router alone chooses explicit Outlook, printer, scanner, Windows/network, clarification, parallel-diagnostic, or escalation edges. Classification never grants consent, approval, or tool authority.

A single specialist is selected only when the leading supported domain meets the confidence threshold and has sufficient margin. Two close, high-confidence domains may enter bounded parallel diagnostics because problems such as Outlook disconnection or print-server failure can originate in Windows networking. Low-confidence results request clarification up to a fixed limit, then escalate. Empty, malformed, unsupported, duplicate, or out-of-range candidates fail closed.

Candidate ordering is canonical, so identical evidence produces the same route. Every decision records the candidates, confidence, reason, outcome, selected domains, and a SHA-256 provenance fingerprint for audit and deterministic replay.
