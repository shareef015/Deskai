# Evidence Explorer

Evidence records are immutable, digest-verified and tenant-scoped. The explorer presents privacy-safe summaries, observation time, computed freshness, allowlisted diagnostic details and complete specialist-to-supervisor handoff lineage. Raw command output, prompts, secrets and endpoint content are never part of this view.

Contradictory observations remain visible under a shared contradiction group instead of being overwritten. Filters narrow by evidence type, source and contradiction state without changing the underlying record set.

Exports require an authorized service-desk, operator or audit role. They contain only selected safe records, a hashed tenant reference and a deterministic export digest.
