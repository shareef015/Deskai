# Frontend type, theme and accessibility quality

External UI data enters through versioned runtime parsers whose inputs are `unknown`. Required fields, primitive types, arrays and unknown-key policy are checked before a typed view model reaches a component. The API mirrors those rules and emits deterministic fingerprints for traceable contracts.

One token system governs workspace surfaces, text, borders, status colors and focus. Quality validation covers WCAG contrast thresholds, semantic main landmarks, live status and alert announcements, visible keyboard focus, 44-pixel interaction targets, reduced-motion preferences, forced-colors support and responsive breakpoints.
