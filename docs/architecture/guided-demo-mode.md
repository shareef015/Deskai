# Guided recruiter demonstration

Eight curated packs demonstrate successful Outlook, printer, scanner, and network support alongside consent decline, approval rejection, verified rollback, and rollback-failure escalation. Each pack advances through greeting, consent, evidence, approval, execution, verification, and closure checkpoints with concise recruiter narration.

Progression is operator-driven. Only an authenticated service-desk engineer or tenant administrator in the synthetic tenant can start, advance, or reset a session. AI identities cannot operate the demo, pack IDs are predefined, and exact confirmation resets the session to its deterministic ready state.

The interface permanently labels the mode as synthetic and states that no production endpoint can be contacted. Replays reference existing regression, conversation, authorization, and remediation artifacts rather than creating ungoverned state.
