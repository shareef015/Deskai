# Human Escalation and Ownership Handoff

Escalation is a governed transfer of responsibility, not an unstructured message. The agent maps a bounded reason taxonomy to endpoint engineering, network operations, security operations, identity and messaging, workplace hardware, major-incident management, L2/L3 support, or service-desk triage. The packet binds tenant, incident, device, graph checkpoint, severity, redacted business impact, evidence references, and latest provenance.

Severity determines an acknowledgement deadline. The owning team and required human role are explicit. A three-hop limit plus visited-team history prevents circular routing, while deterministic packet IDs suppress duplicate handoffs from the same checkpoint. The agent cannot perform the escalated work or alter evidence.

Only an authenticated member of the owning team can acknowledge or report action. Human remediation requires new evidence and returns to technical verification rather than closure. Requests for more information return to clarification; controlled transfers must choose a new valid owner; unresolved work remains escalated with SLA context intact.
