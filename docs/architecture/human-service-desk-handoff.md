# Human Service-Desk Handoff

Escalation creates a digest-bound privacy-safe packet containing reason, severity, impact, evidence references, attempted actions, rollback state and required verification. Raw endpoint output and prompts are excluded.

Tenant-scoped team queues compute SLA state at read time. A qualified resolver explicitly acknowledges the case and becomes its single human custodian. Every custody transition is immutable and records a hashed actor identity.

Human changes are fingerprinted and can never directly close the incident. The resolver returns the case to the supervisor with explicit verification IDs; technical regression checks and employee confirmation remain mandatory.
