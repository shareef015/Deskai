# Incident Workspace and Live Agent Timeline

The incident workspace gives employees and authorized operators one coherent view of conversation context, the current specialist route, privacy-safe evidence references, human decisions, remediation progress, rollback and outcome verification. It never becomes an authorization source: the API revalidates every command and interrupt decision.

The event client reconnects using the last durable cursor, ignores duplicate or out-of-order events, rejects fields outside the public runtime allowlist and bounds rendered history. Live and synthetic modes are visually explicit and changing the environment clears local state to prevent context mixing.

The layout is keyboard-operable, responsive and reduced-motion aware. Human decisions use visible forms, scoped descriptions and expiry information instead of browser prompts or alerts.
