# Knowledge Candidate Publishing

Candidates are de-identified, tenant-scoped and bound to an immutable closure fingerprint plus evidence references. Content digests, quality scores and tenant-local duplicate checks must pass before review.

Authors cannot approve their own candidates. Qualified independent reviewers publish an exact immutable version only after grounding, safety and clarity thresholds pass.

Publication advances the tenant's RAG index generation and records an exact refresh fingerprint. Retirement removes active retrieval, while rollback creates a new auditable version pointing to a previously published digest; history is never rewritten.
