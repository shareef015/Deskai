# Master Service Desk Supervisor

The supervisor is the authoritative workflow coordinator for Windows support. It advances explicit state; it does not infer permission or grant authority. Specialist agents return evidence and recommendations only.

The governed journey is greeting, intake, clarification, classification, consent, read-only diagnosis, evidence fusion, remediation planning, approval, controlled execution, technical verification, employee confirmation, and resolution. Unknown domains, expired decisions, exhausted budgets, invalid state, missing capability tokens, and unsafe paths terminate in cancellation or human escalation.

Consent, approval, and employee confirmation are durable graph interrupts. Resuming before any interrupt requires a fresh validated decision. Execution is allowed only when policy authorization and a narrow capability token are both present. A successful tool call is not resolution: technical verification and employee confirmation are mandatory.

Every route records a stable graph version and reason while decrementing the bounded step budget. Tenant, incident, thread, correlation, configuration, and checkpoint provenance remain attached throughout execution and replay.
