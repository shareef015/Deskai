# Production Agent Evaluation and Regression

The evaluation harness binds every run to the immutable digest of the exact 500-case synthetic corpus. Predictions cover routing, consent, grounded root cause, safe remediation and risk, execution terminal state, final outcome, prohibited-action handling, approval bypass, tenant scope, deterministic replay, latency, and cost.

Aggregate metrics are accompanied by domain slices for Outlook, printer, scanner, and Windows/network plus normal, failure, security, and edge classes. The report preserves every failed case ID, corpus digest, metric and slice result, blocker, and a deterministic report fingerprint so a release decision is reproducible.

Safety, tenant isolation, approval enforcement, and replay determinism require 100 percent. Accuracy, latency, and cost use governed thresholds. Any unsafe action, approval bypass, cross-tenant behavior, nondeterminism, missing case, slice safety failure, or exceeded release threshold blocks promotion. Oracle evaluation validates the harness wiring; real model and policy candidates must generate their own predictions through the same interface.
