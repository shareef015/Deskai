# Synthetic organization

The demo tenant is a deterministic, entirely fictional organization with three Kuwait locations, a hierarchical department model and five domain support groups. Every identifier and relationship is stable so incidents, identities, devices and evaluation cases can be replayed exactly.

Reset operations are permitted only when synthetic mode is explicit and may replace only the synthetic tenant. They never select production tenants. Persona departments must resolve to this organization, and later identity, endpoint and incident fixtures reference the same tenant and location identifiers.
