# Synthetic Outlook incident generation

The generator converts the governed Outlook support catalogue and synthetic Outlook environment into replayable incident fixtures. It emits five variants for every supported incident class and selects only compatible classic or new Outlook clients.

Every case includes symptoms, clarification, device state, content-free diagnostic evidence, knowledge lineage, root cause, risk-rated remediation, approval and rollback expectations, verification, employee response, expected closure, and a compressed timeline. Stable UUIDs, seeds, canonical JSON, and a dataset digest enable exact regeneration.

Generation is offline and side-effect free. It cannot connect to endpoints, use mailbox content, expose credentials, or authorize remediation. High-risk and service-level conditions produce deterministic human escalation.
