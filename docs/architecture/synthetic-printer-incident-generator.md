# Synthetic printer incident generation

The generator joins the governed printer catalogue to deterministic endpoint mappings, queues, ports, drivers, devices, and print servers. Five variants cover every supported printer incident class while retaining exact asset and topology lineage.

Cases include metadata-only evidence, root cause, bounded remediation, risk, approval, rollback, post-state, and a compressed replay timeline. Every path requires submission of the approved synthetic test page, completed-job evidence, physical output confirmation, and employee acknowledgement before resolution.

Generation is offline and cannot operate a printer, inspect a document, change a queue, or authorize a repair. High-risk, administrative, mechanical, electrical, and consumable conditions remain escalations.
