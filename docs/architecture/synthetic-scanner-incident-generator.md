# Synthetic scanner incident generation

The generator joins the governed scanner catalogue to deterministic endpoint, WIA, TWAIN, USB, network, and multifunction-device state. Five variants cover every supported scanner incident class with stable asset and driver lineage.

Cases include content-free evidence, root cause, bounded remediation, risk, approval, rollback, post-state, and compressed replay events. Resolution requires an approved synthetic source sheet, an accessible temporary artifact whose content is never inspected, and explicit employee confirmation.

Generation is offline and cannot operate hardware, inspect scanned content, change WIA or drivers, write to a destination, or approve repairs. High-risk and hardware conditions remain human escalations.
