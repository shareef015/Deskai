# Synthetic Windows and network incident generation

The generator joins the governed Windows/network catalogue to deterministic Windows 10/11 endpoint and network state. Five variants cover each adapter, Wi-Fi, Ethernet, DHCP, DNS, proxy, VPN, route, firewall-aware, service, resource-pressure, and update incident class.

Every case isolates link, IP configuration, gateway, DNS, routing, proxy or VPN, and target-port evidence before remediation. Stable identifiers, seeds, canonical JSON, and a dataset digest support exact replay. Secrets, keys, packet payloads, and unbounded logs are excluded.

Connectivity alone never proves resolution. Each case must re-run its original Outlook, printing, scanning, or endpoint-agent business function and record employee confirmation. Managed firewall changes, full network reset, VPN/proxy policy, and other high-risk actions remain administrator-owned.
