# Operator Handover Checklist

- [ ] Production service ownership assigned.
- [ ] Primary and secondary on-call contacts assigned.
- [ ] Incident severity/escalation policy reviewed.
- [ ] Rollback authority identified.
- [ ] KMS/Vault and break-glass procedures reviewed.
- [ ] OIDC/session incident playbook reviewed.
- [ ] PostgreSQL RLS/backup/restore procedures reviewed.
- [ ] Redis/vector/model-provider degradation paths reviewed.
- [ ] MCP/Windows Outlook/Printer safety controls reviewed.
- [ ] HITL remediation approval procedure reviewed.
- [ ] OpenTelemetry/LangSmith dashboards and alerts accessible.
- [ ] SLO/error-budget dashboard accessible.
- [ ] Queue/backlog and capacity dashboards accessible.
- [ ] Security alert routing verified.
- [ ] Disaster recovery contact tree verified.
- [ ] Demo/recruiter environment confirmed isolated from production.
